Cole aqui o seu token do GitHub. Ele fica só neste navegador e some quando você fechar a aba.

Como gerar o token
  1. Abra github.com/settings/personal-access-tokens
  2. Clique em Generate new token
  3. Em Repository access, escolha só mknod-site
  4. Em Permissions → Repository, marque Contents: Read and write
  5. Gere, copie e cole aqui
